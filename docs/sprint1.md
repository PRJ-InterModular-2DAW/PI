## 🎯 Objetivo del proyecto
Desarrollar una aplicación web de comercio electrónico como proyecto integrador de 2º DAW.
Durante esta primera iteración, se trabaja configuración del entorno, la creación del repositorio, el diseño del aparador (página inicial) y el desarrollo del formulario de contacto con validación.


## 📂 Estructura
- frontend/: HTML, CSS i JS
- backend/: API o servidor
- database/: scripts SQL
- docs/: documentació
